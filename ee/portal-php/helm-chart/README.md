# Gentics Portal | php - Helm Chart

## Introduction

This chart bootstraps a Gentics Portal | php.

## Links

## Update dependency charts

Set gentics-common `version` in `Chart.yml`
```bash
helm dependency update
```

## Building / Release

Helm chart is automatically built with a portal-php release
