The {{%GPJava%}} provides handlers for the available Mesh link:https://www.gentics.com/mesh/premium-features/[plugins].

Mesh plugins usually link:https://www.gentics.com/mesh/docs/plugin-system/[register] API endpoints of the form
`[projectName]/plugins/[pluginName]/...`, and the `BasicPluginHandler` can be used to easily create proxy handlers for
any custom plugins.

## Basic plugin handler

The `BasicPluginHandler` can be used to easily create proxy handlers to forward requests from
`/api/[pluginName]/pass:[*]` to the Mesh endpoint `/api/v2/[projectName]/plugins/[pluginName]/pass:[*]`.

.Example for creating a `BasicPluginHandler` instance
```java
// ...

private final PluginHandler customPluginHandler;

@Inject
public CustomBootstrapInitializer(
        PortalConfig config,
        Vertx vertx,
        Provider<PortalHttpVerticle> verticleProvider,
        MeshRestClient meshClient,
        HandlerProvider handlerProvider) {
    super(config, vertx, verticleProvider, meshClient);

    this.customPluginHandler = new BasicPluginHandler(
        "customPlugin",<1>
        config,
        true,<2>
        handlerProvider);
}

@Override
public void start() {
    // Other initializations.

    deployHttpVerticles(router -> {
        customPluginHandler.addRoutes(router);
    });
}
```
<1> The name of the plugin (needed to create the proxy URLs)
<2> The boolean parameter controls whether the plugin handler may use the admin token when the current request is
    not link:authentication.html#_authentication_cookies[authenticated]. When this argument is `false`, the
    request will be forwarded as `anonymous`.

When more fine grained control over the created proxy handler is needed, the `BasicPluginHandler` constructor can
also be provided with an initialized proxy via `new BasicPluginHandler("customPlugin", customProxy)`.

## Available Mesh plugins

{{%GPJava%}} already comes with handlers for the following commercial {{%Mesh%}} plugins, which just need to be
added in the `BootstrapInitializer`.

### Comment plugin

The `CommentsHandler` will forward all requests for `/api/comment/pass:[*]` to the Mesh endpoints
`/api/v1/[projectName]/plugins/comment/pass:[*]`. Additional information can be found in the plugins
link:https://www.gentics.com/mesh/premium-features/comment/[documentation].

### Favorite plugin

The `BasicPluginHandler` can be used to forward all requests for `/api/favorite/pass:[*]` to the Mesh endpoints
`/api/v1/[projectName]/plugins/favorite/pass:[*]`. Additional information can be found in the plugins
link:https://www.gentics.com/mesh/premium-features/favorite/[documentation].

### Forms plugin

The `FormsHandler` will forward all requests necessary to render forms, or submit data to forms to the Mesh
forms plugin. Endpoints for creating new forms are considered a backend functionality and will not be forwarded by the
portal.

The forms handler will also make sure, that the `forms-data` and `forms-voted` cookies are properly forwarded to
the plugin.

For more information, please check the link:./form-generator.html[dedicated Documentation Page].

### Like plugin

The `LikesHandler` will forward all requests for `/api/like/pass:[*]` to the Mesh endpoints
`/api/v1/[projectName]/plugins/like/pass:[*]`. Additional information can be found in the plugins
link:https://www.gentics.com/mesh/premium-features/like/[documentation].

### Search plugin

The `BasicPluginHandler` can be used to forward all requests for `/api/search/pass:[*]` to the Mesh endpoints
`/api/v1/[projectName]/plugins/search/pass:[*]`. Additional information can be found in the plugins
link:https://www.gentics.com/mesh/premium-features/search/#docs[documentation].
